Weather Data Analyzer

1. Introduction

Weather Data Analyzer is a Python-based project that reads weather information from a CSV file, cleans the data, calculates important weather statistics, and displays graphs.

2. Objectives

- Read weather data from a CSV file.
- Identify missing values.
- Remove duplicate records.
- Fill missing temperature values.
- Calculate average, maximum, and minimum temperature.
- Calculate total rainfall.
- Display temperature and rainfall graphs.

3. Technologies Used

- Python: Main programming language.
- Pandas: Reading and cleaning weather data.
- NumPy: Performing mathematical calculations.
- Matplotlib: Creating graphs and visualizations.
- CSV: Storing weather records.

4. Project Features

1. Displays original weather data.
2. Checks missing values.
3. Removes duplicate records.
4. Fills missing temperature values using the average.
5. Calculates weather statistics.
6. Displays temperature and rainfall graphs.
7. Provides a menu for user selection.
8. Handles a missing CSV file.

6. How to Run the Project

1. Install Python.
2. Install the required libraries:

pip install pandas numpy matplotlib

3. Keep "main.py" and "weather.csv" in the same folder.
4. Open the project in VS Code.
5. Run:

python main.py

7. Conclusion

The Weather Data Analyzer project helps users understand weather information through data cleaning, statistical calculations, and graphical representation. It demonstrates the practical use of Python libraries for data analysis.
